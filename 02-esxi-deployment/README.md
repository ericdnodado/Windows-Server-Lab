# Module 02 – ESXi Deployment

## Overview

This module documents the deployment and initial configuration of VMware ESXi 8.0.3 as a nested hypervisor running inside VMware Workstation.

## Objectives

- Configure VMware Workstation for nested virtualization.
- Create the ESXi virtual machine.
- Install VMware ESXi 8.0.3.
- Configure the ESXi management network.
- Configure the ESXi datastore.
- Validate ESXi management connectivity.
- Capture screenshots as technical evidence.

## Lab Environment

| Component | Configuration |
|---|---|
| Physical Host | Windows PC |
| Virtualization Platform | VMware Workstation |
| Hypervisor | VMware ESXi 8.0.3 |
| ESXi Hostname | ESXI01 |
| Management IP | 192.168.100.100 |
| Network | 192.168.100.0/24 |
